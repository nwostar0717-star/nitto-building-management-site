# 有限会社 日東ビルマネージメント HP

東京都大田区大森西のビルメンテナンス・建物管理会社「有限会社 日東ビルマネージメント」の静的1ページHPです。

## 構成

- `index.html`: 1ページHP本体
- `css/styles.css`: レスポンシブ対応スタイル
- `images/`: 社長写真、参考素材

## 主な内容

- ビルメンテナンス
- リフォーム・修繕
- 警備
- 管理業
- アパート・マンション管理
- 会社概要
- 電話・メール問い合わせ導線

## 確認方法

`index.html` をブラウザで開くと確認できます。静的HTML/CSSのみで動作します。
